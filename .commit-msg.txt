Add real Sentinel-2 STAC/COG ingestion — replaces GIBS browse

Implements real Sentinel-2 L2A band data ingestion from the public
(keyless) Element84 Earth Search STAC API. This is the replacement
for GIBS browse imagery.

Pipeline:
  Renderer: user sets bbox, date range, max cloud, formula
  Main:     POST to https://earth-search.aws.element84.com/v1/search
  Main:     select least-cloudy scene from sorted results
  Main:     open B03/B04/B08/B11 COGs via geotiff (HTTP range)
  Main:     reproject WGS84 bbox to scene CRS with proj4
  Main:     read the matching pixel window, resample to 512x512
  Main:     compute NDVI/NDWI/NBR from real reflectance (DN/10000)
  Main:     convert window extent back to WGS84 for overlay
  Main:     return Float32Array + bbox + metadata to renderer
  Renderer: color-map with formula-specific ramp, overlay on Cesium

Keyless data source:
  https://earth-search.aws.element84.com/v1/
  collection: sentinel-2-l2a

No API key, no registration, no paid credits.
