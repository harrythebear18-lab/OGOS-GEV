Fix climate stations + predictions not loading on plugin activation

Root cause: plugins subscribed to future IPC broadcasts only. If the backend
already broadcast before the plugin activated, it would wait up to 4 minutes
for the next cycle before showing any data.

Fix:
- Add CLIMATE_GET_CURRENT + PREDICTION_GET_CURRENT IPC channels
- Add IPC handlers that return the last known climate state + last prediction
- Store last PredictionUpdate in PredictionEngine + add getLastUpdate() getter
- Add getCurrent() to preload climate + predictions namespaces
- Update climate-stations plugin to request current state on register
- Update PredictionPanel to request current state on mount

Now when the climate-stations plugin is activated, it immediately requests
the last known state (4000+ Argo floats, buoys, etc.) instead of waiting
for the next 4-minute polling cycle.
