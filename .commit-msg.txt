Add hillshade + band-math plugins + AI command interface

Hillshade plugin:
  DEM fetch → compute dispatcher → WebGPU dem-hillshade kernel or
  CPU worker → grayscale canvas → Cesium SingleTileImageryProvider
  Controls: sun azimuth, sun altitude, opacity sliders

Sentinel-2 band-math plugin:
  Fetch GIBS S2 bands (B02/B03/B04/B08/B12) via WMS → WebCodecs
  decode → compute dispatcher → WebGPU ndvi/ndwi/nbr kernel →
  color-mapped canvas → Cesium imagery overlay
  Indices: NDVI (vegetation), NDWI (water), NBR (burn severity)

AI → Engine command interface (action-runner.ts):
  Camera intent tools:
    camera_pan — pan by lat/lng delta
    camera_orbit — rotate heading by N degrees
    camera_look_at — point camera at a target
    describe_viewport — structured metadata (camera, layers, counts, selection)
  Annotation tools:
    add_marker — labeled point on globe
    draw_bbox — bounding box rectangle
    highlight_area — circular highlight
    clear_annotations — remove all AI-created overlays
