AI grounding — whats_in_view, pick_at, pick_object, WorldOverlay tools

Complete the AI → Engine command interface with grounding tools:

whats_in_view:
  Returns structured list of all visible entities + live features
  with screen-space coordinates, geographic coordinates, and
  distance from camera. Answers "what am I looking at?"

pick_at(x, y):
  Pixel-to-world grounding. Picks the globe at screen coordinates,
  returns world coords, entity at that position, and nearby
  entities within a radius. Lets AI reference "that ridge" / "that
  anomaly" by screen position.

pick_object(entityId):
  Select an entity by ID, register in context store, return
  geographic + screen coordinates.

Scene context selectedFeature:
  Wire renderer pick events to scene context so the AI can see
  what the user clicked on (App.tsx → window.api.scene.set).

WorldOverlay tools:
  add_label — persistent label with collision management
  add_card — info card with title/subtitle
  remove_overlay — remove by ID
