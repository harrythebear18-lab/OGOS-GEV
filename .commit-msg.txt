Add volcano plugin — live feeds (EONET + USGS + Smithsonian GVP) + ash simulation

Volcano plugin with three keyless data sources:
  1. NASA EONET — global volcano events (open/closed status)
     Polls every 5 minutes
  2. USGS Volcano Hazards Program — US volcano alerts with color codes
     (GREEN/YELLOW/ORANGE/RED), polls every 2 minutes
  3. Smithsonian GVP WFS — Holocene volcano database (1,215 volcanoes)
     Fetched once on activation (static database)

Visualization:
  - Alert-level colored markers (GREEN/YELLOW/ORANGE/RED)
  - Erupting volcanoes get larger markers + info cards
  - WorldOverlay cards for active eruptions
  - Volcano type, region, threat level, last eruption year

Simulation (ash/SO2 dispersion):
  - Fetches wind direction + speed from Open-Meteo (keyless)
  - Models plume transport downwind with time-stepped simulation
  - Plume height based on alert level (RED=12km, ORANGE=8km, WATCH=5km)
  - Ash concentration fades with distance from source
  - 3D extruded ellipses show ash cloud at altitude
  - 30-minute steps, 12-hour simulation window
  - Updates every 5 seconds
