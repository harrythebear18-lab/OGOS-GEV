AI + web search respect privacy mode — user is locationless when privacy ON

When privacy mode is ON:
- AI system prompt includes strict PRIVACY MODE rules:
  - Never say "your location", "you are near", "from your position"
  - User is LOCATIONLESS — viewport is a region being ANALYZED, not where they ARE
  - Refer to viewport as "the selected region", not "your area"
  - Still answers questions about the region but frames as analysis, not identity
  - If user asks "where am I", responds that privacy mode is on
- Scene context JSON is coarsened to ~1 degree (~111km) resolution
- Location description shows "approx region near X°, Y° (coarsened for privacy)"
- Reverse geocode (place name lookup) is skipped entirely
- Web search tool handler coarsens location to whole degrees
- Web search IPC handler coarsens location when privacyMode flag is passed

Privacy mode flows through:
  PrivacyToggle → App.tsx → AiPanel → ai.chat({privacyMode}) → IPC → chatWithTools({privacyMode})
  → system prompt + context coarsening + web search tool coarsening
