Add WebCodecs VideoEncoder timelapse export — hardware VP9 + WebM muxing

Wires the WebCodecs VideoEncoder to a real timelapse export pipeline
that captures the Cesium canvas and encodes it as a playable WebM
video file using hardware acceleration.

Pipeline:
  Cesium canvas → VideoFrame → VideoEncoder (VP9, hardware) → webm-muxer → .webm

The VideoEncoder uses `hardwareAcceleration: 'prefer-hardware'` which
routes to the GPU's dedicated video engine (NVENC/QuickSync/VAAPI)
when available, falling back to software encode if not.

The webm-muxer library handles EBML/Matroska container muxing so the
output is a valid, playable .webm file — not just raw H.264 chunks.

Features:
  - FPS control (10-60 fps)
  - Duration control (0 = manual stop, up to 120s)
  - Quality presets (1/5/10/20 Mbps)
  - Auto-orbit camera mode (rotates during recording)
  - Orbit speed control
  - Keyframe every 2 seconds for seekability
  - Save to disk via IPC (showSaveDialog)
  - Live status: frames captured/encoded, elapsed time
