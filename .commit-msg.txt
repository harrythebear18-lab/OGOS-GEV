Add acoustic propagation plugin — ISO 9613-1 outdoor sound modeling on real terrain

Planetary acoustic simulator using real terrain, real weather, and
ISO 9613-1 atmospheric absorption physics.

ISO 9613-1 propagation model:
  Lp = Lw - A_div - A_atm - A_gr - A_bar + D

  A_div = 20*log10(r) + 11        geometric divergence (spherical)
  A_atm = alpha(f,T,RH,P) * r     atmospheric absorption (per band)
  A_gr  = ground effect           source/receiver height + ground type
  A_bar = barrier/terrain         DEM line-of-sight shadow (Maekawa)
  D     = directivity             speaker H/V pattern + rotation

Physics implemented:
  - ISO 9613-1 atmospheric absorption (oxygen + nitrogen relaxation,
    classical thermal/viscous, temperature/humidity/pressure dependent)
  - Spherical geometric divergence (6 dB per doubling)
  - Ground effect (hard/porous/mixed, path-length interference)
  - Terrain barrier attenuation (DEM line-of-sight, Maekawa formula)
  - Speaker directivity (horizontal off-axis attenuation)
  - Wind refraction (downwind enhancement, upwind shadow zones)

Data sources (all keyless):
  - DEM: AWS Terrarium tiles (terrain shadowing)
  - Weather: Open-Meteo (temperature, humidity, wind, pressure)
  - Ground type: user-selectable (hard/porous/mixed)

Plugin UI:
  - Place Source button → click on globe to drop speaker
  - Lw (power), frequency (octave bands), height, H/V coverage,
    rotation, ground type controls
  - Compute SPL Map → 256x256 grid → color-mapped heatmap overlay
  - Wind direction arrow rendered from source
  - Multi-source energy summation (multiple speakers)
