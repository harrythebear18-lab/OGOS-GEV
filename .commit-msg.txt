Add WebCodecs VideoDecoder drone footage frame extraction

Wires the WebCodecs VideoDecoder to a real MP4 demux + frame
extraction pipeline using mp4box for container demuxing and
VideoDecoder for hardware-accelerated decode.

Pipeline:
  MP4 file → mp4box (demux) → EncodedVideoChunk → VideoDecoder
  (hardware) → VideoFrame → ImageBitmap → thumbnails

The VideoDecoder uses `hardwareAcceleration: 'prefer-hardware'`
which routes to the GPU's dedicated video decode engine
(NVDEC / QuickSync / VAAPI) when available.

This replaces the broken `decodeVideo` in webcodecs.ts which
tried to feed a raw blob as a single EncodedVideoChunk. That
approach does not work for real video files because an MP4
container contains audio, metadata, and multiple frames — not
a raw Annex-B bitstream.

mp4box provides:
  - Track metadata (width, height, fps, codec)
  - Sample list (each sample = one encoded frame)
  - Sample data extraction
  - Timestamp / duration / sync (keyframe) info

Features:
  - Load MP4 file via file picker
  - Max frames control (1-300)
  - Sample interval (extract every Nth frame)
  - Hardware decode status
  - Thumbnail generation
  - Real-time progress during extraction
  - Frame count, video resolution, codec, FPS display
