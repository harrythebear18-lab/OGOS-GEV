Port GEV AI architecture — analyst engine, action runner, detection overlay, context store, annotation resolver

Analyst Query Engine (analyst/analyst-engine.ts):
- Pure query logic over live features (aircraft, vessels, fires, quakes, satellites)
- Spatial scope: view, radius, bbox, anywhere
- Attribute filters: gt, lt, eq, contains on any meta field
- Sort by distance or any numeric field
- Follow-up queries with memory of last result set
- Summary stats (count, min, max)

Context Store (analyst/context-store.ts):
- Shared entity selection and tracking state
- Entity registry with per-entity metadata
- Click selection + camera tracking
- Event-driven subscriptions for panels, AI, detection overlay

Annotation Resolver (analyst/annotation-resolver.ts):
- Nominatim geocoding (free, no key)
- Overpass building/area outline fetching with multi-server fallback
- Caching with TTL for negative results
- resolveAnnotationTarget: geocode + optional footprint

Action Runner (analyst/action-runner.ts):
- 8 tool functions the LLM can call:
  fly_to, zoom_to_globe, set_layer_visibility, query_data,
  select_nearest, track_entity, stop_tracking, resolve_place
- Layer alias normalization (planes→aircraft, ships→vessel, etc.)
- Bound to Cesium viewer + plugin manager + live features + view context

Detection Overlay (analyst/detection-overlay.ts + plugins/detection-plugin.ts):
- Screen-space corner brackets + labels over tracked objects
- 4 density modes: OFF / SPARSE (15) / BALANCED (50) / DENSE (200)
- 4 themes: normal, retro, surveillance, thermal (with scanlines)
- Per-layer weighting (storms > quakes > aircraft > vessels)
- Distance-scaled bracket size + label with callsign/type/distance

Vision Plugin Integration:
- Tool Use toggle — enable/disable LLM tool calling
- Chat (with tools) — sends prompt with live data summary + tool descriptions
- Query Live Data — direct analyst engine query from natural language
- Tracked Objects display — count of live features loaded
- Subscribes to live updates for analyst queries
